# Пример проекта: ежемесячная презентация из Excel

Учебный проект к **уроку 9 «Первый проект»** курса «ИИ без воды». Скрипт берёт управленческие данные из Excel,
заполняет фирменный шаблон pptx и сохраняет готовую презентацию. Все цифры выдуманы.

## Что внутри

| Файл | Зачем |
|---|---|
| `spec.md` | **Спецификация** — главный документ: что собираем, откуда каждая цифра, какие проверки |
| `template.pptx` | Демо-шаблон (в жизни — ваша ручная презентация с метками `{{…}}`) |
| `build_presentation.py` | Скрипт сборки: проверка → расчёт → заполнение шаблона → сохранение |
| `data/2026-08`, `data/2026-09` | Выдуманные исходники за два месяца |
| `out/Отчёт_2026-09.pptx` | Готовый результат для сентября |
| `make_demo_data.py`, `make_template.py` | Создают демо-данные и демо-шаблон; в реальном проекте не нужны |

## Как запустить

**На своём компьютере** (нужен Python 3.10+ и две библиотеки):

```
pip install python-pptx openpyxl
python build_presentation.py data/2026-09
```

**Без установки Python** — в песочнице выполнения кода вашего ИИ-ассистента (например, Code Interpreter в LibreChat):
загрузите в чат `build_presentation.py`, `template.pptx` и файлы месяца и попросите:
«Запусти build_presentation.py без изменений на загруженных файлах (папка data/2026-09) и дай скачать результат».
Точные шаги зависят от версии сервиса — подробнее в уроках 14–16.

## Если что-то не так с исходниками

Скрипт не собирает презентацию «как получится», а останавливается и объясняет, что исправить:

```
Презентация НЕ собрана: исходники не прошли проверку.
  • Лист «ЖД»: нет строки «Оборот вагона, сут»
  • «Сводка»: факт выручки — сумма направлений 1 605 ≠ строке «Итого» 1 650
```

## Как приспособить под свою презентацию

1. Возьмите ручную презентацию прошлого месяца и сохраните копию как `template.pptx`.
2. Замените меняющиеся тексты метками `{{период}}`, `{{выводы}}` и т. п.; дайте имена таблицам и графикам.
3. Перепишите `spec.md` под свои слайды и исходники — это главное, и делает это владелец отчёта.
4. Попросите ИИ обновить `build_presentation.py` по новой спецификации — по шагам, как в уроке 9.
5. Примите результат: прогон на прошлом месяце и сверка с ручной версией.
