# ИИ без воды

Курс по искусственному интеллекту, от основ к практике:
- как устроены модели;
- промптинг;
- вайбкодинг;
- ИИ-агенты;
- локальный ИИ.

Уроки делаются в PDF. По итогам курса здесь появится интерактивный тренажёр на HTML.

## Что где лежит

```
lessons/      уроки в PDF
src/          исходники уроков (Python + ReportLab)
CLAUDE.md     контекст проекта для Claude Code
```

## Как пересобрать урок

```
pip install reportlab
python3 src/lesson04.py
```

PDF появится в папке `lessons/`. Нужны шрифты DejaVu: на Linux они обычно уже стоят, на macOS и Windows их нужно установить.
